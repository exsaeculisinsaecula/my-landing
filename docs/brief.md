# 나의 페이지 기획
- 주제: 사진 동호회 「찰나」 — 주말 사진 산책과 한 장 피드백 모임
- 방문자의 구체적 상황: 폰카메라로 일상을 찍기 시작한 직장인·학생. SNS에는 올리지만 구도·빛·보정을 어디서부터 배워야 할지 모른다. 주말에 혼자 나서기엔 무겁고, 비싼 장비를 가진 모임은 부담스럽다.
- 방문자가 겪는 문제: 찍은 사진을 보여줄 곳과 이야기할 사람이 없다. 장비 자랑이 많은 모임에서 초보로 끼기 어렵다. 어떻게 늘어야 하는지 피드백을 받을 기회가 없다.
- 내가 약속할 내용: 매주 토요일 오전 동네에서 함께 걸으며 찍고,참가자마다 완성작 한 장씩 나누며 이야기합니다. 장비 제한 없이 폰카메라도 환영합니다. 교육용 가상 모임이며 실제 운영 실적을 뜻하지 않습니다.
- 가장 중요한 행동과 버튼 문구: 첫 모임 참여 신청 → 버튼 문구 「첫 모임 참여하기」
- 섹션 순서와 각 섹션에 넣을 자기 글:
  1. Hero — 「한 장의 사진에, 오늘을 담으세요.」 / 주말 사진 산책과 피드백 모임 소개
  2. 장점(카드 4개) — 주말 사진 산책 · 한 장 피드백 · 초보 환영 장비 · 계절별 촬영 미션
  3. 내 소개 — 사진을 혼자 취미로 시작해 3년간 주말마다 나갔던 경험. 초보 시절 피드백이 필요했던 기억으로 모임을 기획함.
  4. FAQ — 처음 참여·장비·비 오는 날
  5. 문의 폼 — 입력 검사 연습(전송하지 않음)
- 이미지 권리·출처: 직접 그린 SVG 삽화(카메라)만 사용. 외부 사진·아이콘은 복제하지 않음.
- 제작 가정·실제 운영 여부: 교육용 가상 모임 페이지. 실제 참가 신청·결제·계정 기능 없음. 문의 폼은 입력 검사만 시연하며 서버로 전송하지 않음.
